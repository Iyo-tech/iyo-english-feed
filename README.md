# IYO 영어 훈련 — 개인 팟캐스트 목록

형준님의 영어 학습용 **개인 팟캐스트 목록**이 들어 있는 저장소입니다.

## 여기 있는 것
- NPR이 **이미 전 세계에 공개한** 방송의 제목과 음원 주소를 모아둔 목록 파일 하나

## 여기 없는 것
- 학습 교재 · 개인 기록 · 열쇠 · 그 밖의 IYO 자료 (전부 비공개 저장소에 있습니다)

## 어떻게 갱신되나
매일 새벽, 비공개 저장소의 자동화가 그날 고른 클립 하나를 이 목록에 추가합니다.

음원은 이 저장소에 저장되지 않습니다 — NPR 서버를 가리키는 **주소만** 담습니다.
